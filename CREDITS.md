# Credits

What the game uses that we didn't make ourselves. The title screen's Credits page
(`scripts/menus/credits.gd`, DECISIONS 090) is a short version of this list: when a line
is added here, add it there too.

## Art

- **Cozy Village & Farm — 16x16 Top-Down Mega Asset Pack** (CozyVillageFarm v1.0), by
  **Michel Clauwaert**. The ground tiles: grass, paths, paving, soil, the pond, sand and
  the sea, and their edges (DECISIONS 076, 077); the cliffs in the calm test (DECISIONS
  078). Used
  under the pack's licence: use in the game is allowed, passing the files on is not, so
  the pictures made from it (`assets/tilesets/cozy/`) are not in the repository.

- From the same author, bought 2026-11-20: **Coast, Beach & Fishing** (CoastBeachFishing
  v1.0) for the Cove's harbour test (DECISIONS 080) and its harbour props; **Seasons &
  Festivals** (SeasonsFestivals v1.0) for the festival dressing; **Game UI Kit: Menus,
  HUD, Dialogue & Fonts** (GameUIKit v1.0) for the wooden UI test; and Cozy Village &
  Farm's props (DECISIONS 081). Same licence: use in the game, never pass the files on, so
  what is taken from them (`assets/tilesets/cozy/`, `assets/packs/`) stays out of the
  repository too.

- From the same author, 2026-11-21: **Cozy Interiors & Town Life** (CozyInteriors v1.0) for
  the shops', farmhouse's and tavern's furniture (DECISIONS 083). Same licence, so
  `assets/packs/interiors/` stays out of the repository.
