# Fonts

| File | Font | Author | Licence | Used for |
|---|---|---|---|---|
| monogram.ttf | monogram, with four characters added (· – — ×) | Vinícius Menézio (datagoblin) | CC0 (see monogram_LICENCE.txt) | All text: dialogue, menus, the HUD, at size 16 |
| PixelifySans.ttf | Pixelify Sans (variable weight) | The Pixelify Sans Project Authors (Stefie Justprince) | SIL Open Font Licence 1.1 (PixelifySans_OFL.txt) | Headings (menu titles, the speaker's name), at size 13 |

Both are set once in `assets/ui/theme.tres` (DECISIONS 074); sizes are in
`scripts/ui_style.gd`. The credits screen (Stage 26) names both. The OFL lets the
font ship inside the game; it must not be sold on its own, and the licence file
travels with it.
